# تطبيق «لَمّة» للهاتف - Native Android (Kotlin + Jetpack Compose)

تطبيق هاتف أصلي 100% مبني بأحدث تقنيات أندرويد الرسمية (**Pure Native Kotlin + Jetpack Compose**)، بدون أي استخدام لـ WebView أو TWA أو Capacitor أو Cordova.

---

## 🏗️ البنية التقنية (Architecture)

* **لغة البرمجة:** Kotlin 2.0+
* **واجهة المستخدم:** Jetpack Compose مع Material 3
* **التنقل وإدارة الحالة:** Navigation Compose + Coroutines + Kotlin Flow + StateFlow
* **قاعدة البيانات والتزامن الحي:** الحزمة الرسمية **Supabase Kotlin SDK** (`postgrest-kt` + `realtime-kt` عبر محرك Ktor CIO)
* **التخزين المحلي الآمن:** Jetpack DataStore Preferences
* **عرض الصور:** Coil 2.7.0 (Compose)
* **المؤثرات الصوتية:** Android `SoundPool` / `AudioTrack` البرمجي لنغمة إشعار الرسائل الواردة

---

## 🔒 القيود المعمارية الصارمة (Negative Constraints)

1. **انعدام استخدام WebView أو TWA:** تطبيق أندرويد نيتف كامل يعتمد على Compose Composables الأصلية (`LazyColumn`, `Surface`, `OutlinedTextField`, إلخ).
2. **انعدام التسجيل الصوتي:** لا يحتوي التطبيق على أي واجهات تسجيل ميكروفون أو MediaRecorder، محتفظاً فقط بنغمة رنين إشعار ناعمة عند ورود رسالة جديدة.
3. **صفر استهلاك للمساحة السحابية (Zero-Database-Quota):**
   * ضغط الصور عبر `android.graphics.Bitmap` (الحد الأقصى 900 بكسل وجودة 72%).
   * حفظ الصور محلياً في ذاكرة الهاتف الداخلية (`Context.filesDir/lamma_media`).
   * إرسال معرف مؤقت `media-stub:<id>` في قاعدة البيانات لا يستهلك أكثر من بضعة بايتات، مع توفير زر «حفظ في الاستوديو» عبر `MediaStore API` وزر «مسح كاش الصور» في الإعدادات.

## 🚀 البناء والتشغيل عبر CI/CD

ملف العمل المؤتمت في `.github/workflows/build-android-apk.yml`:
* يبني حزمة الـ APK تلقائياً باستخدام JDK 17 و Android SDK.
* يوقّع الحزمة ويستخرج ملف `lamma.apk`.
* يرفع الملف كـ Artifact جاهز للتحميل والتثبيت المباشر.
