# دردشة العائلة (Family Chat)

تطبيق ويب عائلي خفيف وسريع، مبني بواجهة عربية كاملة، يدعم المراسلة الفورية، مشاركة الصور، التفاعلات السريعة، والتنبيهات المثبتة بتكلفة تشغيلية منعدمة.

## المميزات الأساسية

1. **انضمام فوري بدون تعقيد**: شاشة دخول واحدة تتيح لأفراد العائلة اختيار الاسم واللون المفضل ورمز الغرفة المشتركة في ثوانٍ معدودة دون الحاجة لحسابات أو كلمات مرور.
2. **محادثة فورية مباشرة**: إرسال الرسائل النصية، اقتباس الردود، والتفاعل السريع بالرموز التعبيرية (❤️، 👍، 😂، 🤲).
3. **مشاركة الصور**: ضغط ومشاركة الصور بجودة عالية وبشكل فوري عبر المتصفح.
4. **تنبيه عائلي مثبت**: شريط أعلى المحادثة لتثبيت الملاحظات والتذكيرات المهمة (مواعيد، طلبات، مهام) يمكن لجميع أفراد الأسرة تحديثه أو إزالته.
5. **وضع التشغيل المزدوج**:
   - يدعم الاتصال المباشر بقاعدة بيانات Supabase عند توفر المفاتيح.
   - وضع محلي تلقائي (Graceful Local Mode) عبر `localStorage` و `BroadcastChannel` لتزامن التبويبات الفوري عند عدم ضبط المفاتيح.

## متطلبات التشغيل

- Node.js (الإصدار 18 فما فوق)
- npm أو pnpm أو yarn

## التثبيت والتشغيل

1. تثبيت الحزم:
```bash
npm install
```

2. بناء التطبيق للتأكد من خلوه من الأخطاء:
```bash
npm run build
```

3. تشغيل خادم التطوير:
```bash
npm run dev
```

افتح المتصفح على العنوان `http://localhost:3000`.

## ضبط خادم Supabase (اختياري)

إذا أردت تفعيل المزامنة السحابية عبر Supabase:
1. أنشئ مشروعاً جديداً في منصة [Supabase](https://supabase.com).
2. نفّذ ملف الاستعلامات `supabase/schema.sql` في محرر SQL الخاص بـ Supabase.
3. انسخ الملف `.env.example` إلى `.env.local` وأضف المفاتيح:
```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key-here
```
